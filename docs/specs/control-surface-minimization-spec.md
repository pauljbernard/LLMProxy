# Control Surface Minimization Specification

## Purpose

This document limits the number of controls that must be operated manually in the first version.

## V1 Manual Controls Allowed

- candidate approval and rejection
- benchmark selection
- promotion approval
- release approval

## V1 Automation Required

- request logging
- routing decision logging
- export manifest generation
- migration application path
- health verification

## Anti-Goal

Do not automate every workflow in v1 if manual approval preserves clarity and reduces operator burden.

## Rule

Manual controls should exist only where they materially reduce risk or simplify early operation.
