# Time to First Value Specification

## Purpose

This document sets target expectations for how quickly an operator should realize value.

## Initial Targets

- `Proxy Only` usable in under `1 hour` once prerequisites are available
- `Proxy + Capture` usable in under `1 day`
- first benchmark and economics baseline in under `2 days`
- first specialist training experiment in under `1 week`

## Rule

If the implementation makes these targets implausible without strong justification, the system has likely become too heavy for early adoption.
