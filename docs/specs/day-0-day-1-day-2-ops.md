# Day 0 / Day 1 / Day 2 Operations

## Purpose

This document separates setup work from routine operation and incident handling.

## Day 0: Initial Setup

- provision environment
- configure secrets
- deploy base runtime
- verify health and logging
- verify provider connectivity

## Day 1: First Value

- route traffic through proxy
- capture and inspect requests
- enable candidate logging
- run first benchmark and economics baseline

## Day 2: Ongoing Operation

- review dashboards and alerts
- review spend and route mix
- review candidate approval/export flow
- evaluate and promote only when gates pass
- perform rollback when necessary

## Rule

The system should provide value on Day 1 without requiring the full continuous training loop.
