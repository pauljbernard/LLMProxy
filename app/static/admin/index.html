The dataset version to train from — use Train on a version row in the Data Pipeline panel to fill this in. Its domain and train/validation/test file paths are pulled in automatically; the run starts in pending status and is processed asynchronously by the configured trainer.

Action Form

                  
Run Evaluation

                  

                  

                    
                    
                    
The training run to evaluate — use Evaluate on a run row to fill this in. Its dataset version determines the domain this evaluation measures against; the request is rejected if either the training run or its dataset version can't be found.

                  

                  

                    
                    
                    
Optional. Leave blank to benchmark against the frontier model configured for this domain — falling back to the proxy's configured Anthropic model if no domain-specific baseline is set.
