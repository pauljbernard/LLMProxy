# Quickstart: llmProxy Foundation

## Minimal Path

1. review `.specify/memory/constitution.md`
2. review `spec.md`, `plan.md`, and `tasks.md`
3. install dependencies
4. start local Postgres and Redis using `infra/compose/docker-compose.yml`
5. run the API service
6. verify `/health`
7. run a smoke request against `POST /v1/chat/completions`
